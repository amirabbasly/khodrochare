# استراتژی مستقل Yandex

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## ثبت تصمیم و وضعیت

| مورد | نتیجه |
|---|---|
| مشکل | نبود مالکیت تأییدشده، داده Query و منطقه عملیاتی در پنل |
| شواهد | Yandex connector unsupported؛ src/app/robots.ts؛ layout metadata |
| شدت | P2 |
| اثر تجاری | سهم واقعی ورودی روسی/فارسی و ارزش تجاری نامعلوم |
| راه‌حل | ابتدا مالکیت، crawl و شاخص‌های خود Yandex؛ سپس تصمیم سرمایه‌گذاری |
| اقدام انجام‌شده | پشتیبانی verification یاندکس و گروه صریح YandexBot/YandexImages |
| نتیجه تست | robots unit و metadata محلی پاس؛ پنل تست نشده |
| وضعیت نهایی | آماده پیکربندی؛ عملکرد اندازه‌گیری نشده |

## ترتیب کار
- `NEXT_PUBLIC_YANDEX_SITE_VERIFICATION` از پنل واقعی در build قرار گیرد؛ تگ واقعی در HTML تأیید و مالکیت ثبت شود.
- sitemap و robots در [Yandex Webmaster](https://yandex.com/support/webmaster/en/) بررسی؛ indexing، diagnostics، duplicates، موبایل و security خروجی جدا داشته باشند.
- برای منطقه فقط تهران/کرج/شمال اعلام‌شده و نشانی تأییدشده استفاده شود؛ تنظیم منطقه روسیه یا دفتر جعلی برای رتبه ممنوع.
- position، impressions و clicks از Yandex وارد شوند؛ عدد Google قابل انتقال نیست. زبان فارسی و محتوای اصلی server-rendered حفظ شود؛ ترجمه روسی خودکار بدون مخاطب واقعی توصیه نشد.
- Metrica نصب نشد: شناسه، بررسی حریم خصوصی، رضایت لازم و تصمیم درباره session replay در دسترس نیست. ورودی فرم، شماره، موقعیت دقیق و session replay حساس بدون مجوز جمع نشود.

## ربات و منطقه
[تأیید ربات یاندکس](https://yandex.com/support/webmaster/en/robot-workings/check-yandex-robots): reverse DNS با مرز دامنه yandex.ru/net/com و سپس forward DNS منطبق با IP اولیه. UA به‌تنهایی معتبر نیست. لیست IP حدسی ساخته نشود. Crawler تست محلی با UA مصنوعی اثبات crawl توسط Yandex نیست.

## خروجی قابل سنجش
هفته‌ای یک snapshot پنل؛ خطای crawl و URLهای canonical انتخاب‌شده، تعداد صفحه قابل کشف و تبدیل‌های دارای منبع Yandex. اگر داده کم است بازه بزرگ‌تر با ذکر محدودیت، نه درصدهای ناپایدار روزانه.
