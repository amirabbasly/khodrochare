# اندازه‌گیری تبدیل با تفکیک مراحل

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## ثبت تصمیم و وضعیت

| مورد | نتیجه |
|---|---|
| مشکل | کلیک تماس، ورود اپ، دریافت اطلاعات و تأیید سفارش یکی نیستند |
| شواهد | analytics-events.tsx؛ online-request-brief.tsx؛ API موجود service-requests |
| شدت | P1 |
| اثر تجاری | بدون funnel واقعی، افزایش traffic ممکن است با مشتری اشتباه گرفته شود |
| راه‌حل | event taxonomy کم‌داده و اتصال به پذیرش واقعی backend با مجوز |
| اقدام انجام‌شده | click_to_call، app_open، app_download واقعی و whatsapp_click افزوده؛ legacy حفظ شد |
| نتیجه تست | lint/typecheck و unit پاس؛ اتصال GA4/تبدیل backend تأیید نشده |
| وضعیت نهایی | instrumentation بخشی آماده؛ end-to-end و consent باز |

| event | معنای درست | وضعیت |
|---|---|---|
| click_to_call | کلیک tel، نه مکالمه موفق | افزوده؛ click_tel قدیمی برای سازگاری حفظ شد |
| app_open | کلیک ورودی app علامت‌گذاری‌شده | افزوده؛ نه ثبت یا نصب |
| app_download | کلیک لینک download با APK واقعی | افزوده مشروط؛ APK منتشرنشده باعث رویداد دانلود نمی‌شود |
| whatsapp_click | کلیک مسیر WhatsApp | alias جدید؛ وجود لینک/کانال فعال تأیید نشده |
| request_form_start | تعامل واقعی فرم ثبت | تعریف برای backend/فرم اصلی؛ کلیک #request به‌تنهایی معیار نیست |
| request_form_submit | ارسال واقعی پذیرفته‌شده فرم | بدون integration محصول فعال اعلام نشد |
| request_confirmed | پذیرش عملیاتی قطعی از منبع معتبر | عمداً از browser click/201 received تولید نمی‌شود |
| support_contact | ارتباط با پشتیبانی با برچسب نقش خط | پس از تأیید نقش شماره‌ها |
| service_request_prepared/attempt/received | وضعیت‌های قدیمی ابزار دریافت درخواست | حفظ؛ received همان اعزام قطعی نیست |

## حریم خصوصی و منبع حقیقت
شرح خرابی، شماره مشتری، موقعیت دقیق، متن فرم، OTP و reference قابل ردیابی به GA ارسال نشود. رویداد جدید فقط path و placement/platform/app ثابت دارد. cross-domain login اپ و سفارش در این سورس قابل اثبات نیست. اگر GA و GTM هم‌زمان مصرف می‌شوند legacy+alias را هر دو به‌عنوان یک conversion نشمارید؛ یک رویداد استاندارد به ازای هر مرحله.

GA4 فقط با NEXT_PUBLIC_GA_ID لود می‌شود؛ فعال بودن property، consent manager، DebugView و ذخیره رویداد واقعی بررسی نشده. تگ جدید Metrica/GTM یا recorder بدون اجازه نصب نشد. به consent لازم و سیاست حریم خصوصی قبل از فعال‌سازی احترام بگذارید. درآمد یا نرخ تبدیل فرضی درج نشد.
