# راهنمای انتشار و GSC برای خوشه جدید

## وضعیت اجرا
سه صفحه جدید با معرفی مثبت خدمات و دعوت به اقدام ویرایش شدند. آمار بیش از ۱۰۰۰ سفیر و بیش از ۵۰ هزار سرویس، مطابق اطلاعات مالک ثبت شده‌اند؛ تضمین عددی برای نتیجه خدمت، زمان حضور یا رتبه گوگل افزوده نشده است. هیچ ماژول در حال توسعه به‌عنوان قابلیت عملیاتی قطعی معرفی نشده است.

## پس از انتشار واقعی
پوش Git به‌تنهایی تایید Deploy نیست. ابتدا سه URL را روی دامنه زنده باز کنید:
- https://khodrochare.ir/guides/night-roadside-access-planning
- https://khodrochare.ir/guides/mobile-mechanic-visit-preparation
- https://khodrochare.ir/guides/online-towing-destination-coordination

## Search Console
۱. در Sitemaps، وضعیت `https://khodrochare.ir/sitemap.xml` و آخرین خواندن را بررسی کنید. حذف/ثبت مجدد روزانه لازم نیست. این نسخه پروژه ۴۸۱ URL قابل‌ایندکس دارد؛ عدد GSC می‌تواند تا خزش تازه یا به علت Sitemapهای قبلی متفاوت باشد.
۲. برای هر سه URL، URL Inspection و Test live URL را اجرا کنید؛ پاسخ موفق، اجازه ایندکس و HTML را بررسی کنید. canonical اعلامی باید همان URL باشد؛ canonical انتخابی گوگل در گزارش نسخه ایندکس‌شده بررسی می‌شود.
۳. پس از تایید نسخه صحیح، برای هر URL یک بار Request indexing بزنید. این درخواست تضمین ایندکس یا رتبه نیست.
۴. لندینگ `/امداد-خودرو-آنلاین` را هم بررسی کنید تا لینک به راهنماهای جدید در نسخه زنده وجود داشته باشد.
۵. در Performance فیلتر Page هر راهنما و Queryهای موضوعی همان صفحه را بررسی کنید: هماهنگی امداد شبانه، آمادگی حضور مکانیک و مقصد یدک‌کش آنلاین. داده برند و غیربرند را جدا نگه دارید.
۶. پس از جمع‌شدن داده، بازه‌های یکسان ۲۸روزه و device یکسان را مقایسه کنید؛ داده کم به‌تنهایی مبنای تغییر روزانه عنوان یا ساخت صفحات مشابه نیست.

## نتیجه محلی
Lint، build، ۱۸۰ تست واحد و بررسی SEO production محلی موفق بودند. مقایسه ۲۵۳ فایل محافظت‌شده، بدنه SSR و مقصد لینک‌های صفحه اصلی بدون تغییر بود. مقایسه تصویری مرورگر و دسترسی مستقیم به حساب GSC انجام نشده است.
