# تغییرات اجراشده و rollback

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## تغییرات واقعی
1. `service-promise.tsx`: فقط متن دیداری «معیار مقایسه» از th اول حذف شد؛ چهار ستون، scope، عرض‌ها و محتوای ردیف‌ها حفظ؛ aria-label برای نام دسترس‌پذیر باقی ماند. تست browser انتظار header خالی دارد.
2. `robots.ts`: تصحیح کامنت گمراه‌کننده training/GEO؛ YandexBot، YandexImages و PerplexityBot گروه صریح با /api exclusion؛ دسترسی مؤثر آن‌ها پیشتر از wildcard نیز مجاز بود، پس این کار «رفع مسدودی اثبات‌شده» نیست. GPTBot بدون تصمیم مالک تغییر نکرد.
3. `layout.tsx`: env verification اختیاری Google/Bing/Yandex؛ بدون token واقعی تگ ساختگی نمی‌سازد.
4. `analytics-events.tsx`: eventهای شفاف اضافه و legacy حفظ؛ request_confirmed جعلی ایجاد نشد.
5. CLI `seo-inventory.ts`: crawl local، URL classification، metadata، schema types، گراف depth/inbound و flag تاریخ.
6. CLI `indexnow.ts` و lib: dry-run پیش‌فرض، host ثابت، key proof، batch/lock/cooldown/state/log. API جدید، cron فعال یا ارسال خارجی ایجاد نشد.
7. CLI `citation-monitor.ts`: فقط observations واقعی ورودی را validate و summarize می‌کند؛ بدون ادعای دسترسی API موتور.
8. `tests/unit/multi-engine-seo.test.ts`، `tests/browser/seo-measurement.spec.ts` و به‌روزرسانی test جدول؛ `.cache/` در gitignore برای state.
9. اسناد و CSVهای `docs/seo/`؛ داده performance فرضی یا محتوای جدید انبوه ساخته نشد.

## دست‌نخورده‌های مهم
نام شرکت به‌دلیل تعارض سندی تغییر نکرد؛ هیچ شماره/مجوز/branch/Review ساخته نشد. sitemap date بدون منبع تغییر نکرد. طراحی، routeها و عملکرد اپ/فرم/API موجود حفظ شدند؛ community برنگشت. هیچ URL به موتور ارسال نشد و هیچ ابزار حسابی نصب/فعال‌شده اعلام نشد.

## Rollback
پایه انتشار قبلی از origin با commit `e0fb3e4` قابل ارجاع است؛ به‌دلیل سابقه checkout اختلاف‌های قدیمی در working tree، همه آن‌ها تغییر این ممیزی نیستند. به جای reset --hard، در انتشار فقط patch این مرحله را revert کنید؛ برای فایل‌های source از نسخه تأییدشده قبل restore هدفمند پس از حفاظت از تغییرات هم‌زمان. برای غیرفعال‌سازی verification فقط envهای جدید حذف و rebuild. برای IndexNow اجرای CLI/cron متوقف؛ چیزی در مسیر درخواست مشتری نصب نشده است.
