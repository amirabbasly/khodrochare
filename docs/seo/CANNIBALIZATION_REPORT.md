# هم‌پوشانی هدف صفحات

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## ثبت تصمیم و وضعیت

| مورد | نتیجه |
|---|---|
| مشکل | هم‌پوشانی بالقوه بین خانه، تهران، /تهران/امداد-خودرو، آنلاین و مقالات |
| شواهد | عنوان‌ها و H1 واقعی در SEO_URL_INVENTORY.csv؛ داده Query × Page نداریم |
| شدت | P1 برای بررسی؛ cannibalization قطعی نشده |
| اثر تجاری | امکان پراکندگی landing تجاری؛ اثر اندازه‌گیری نشده |
| راه‌حل | تفکیک intent و سنجش Query/Page قبل از ادغام |
| اقدام انجام‌شده | Keyword map پیشنهادی تهیه شد؛ حذف/canonical/redirect جدید اعمال نشد |
| نتیجه تست | canonicalهای موجود و 15 ریدایرکت تست شدند |
| وضعیت نهایی | فرضیه قابل آزمون؛ نیازمند داده |

| مجموعه URL | نقش پیشنهادی | تصمیم فعلی |
|---|---|---|
| / و /تهران | برند و خدمات کلی در برابر درخواست محلی تهران | حفظ هر دو؛ Query/Page لازم |
| /تهران و /تهران/امداد-خودرو | هاب محلی در برابر خدمت خاص همان شهر | ارزش افزوده/landing واقعی بررسی؛ ادغام خودکار نشد |
| /امداد-خودرو-آنلاین و /app | ثبت/هماهنگی در برابر امکانات/نصب | intent متفاوت؛ لینک متقابل حفظ |
| /pricing و ابزار حمل | چارچوب هزینه در برابر محاسبه/برآورد | فرمول و محدودیت ابزار به صفحه قیمت لینک شود |
| /battery و صفحات شهر/باتری | برق/عیب‌یابی در برابر سفارش محلی | به جای تکرار، لینک زمینه‌ای |
| مقاله‌های تهران و صفحات محلی | آموزشی/تصمیم در برابر سفارش | مقاله صرف نام محله تولید نشود |

وجود چند URL برای یک Query لزوماً cannibalization نیست. نشانه جدی: تعویض پی‌درپی landing نامتناسب، افت هم‌زمان CTR/conversion و مشابهت intent در بازه برابر. `scripts/search-monitor.ts` با CSVهای query,page,clicks,impressions,position فرصت بازبینی می‌دهد؛ خروجی آن اثبات علت نیست. داده تجمیعی ناقص یا ردیف‌های حذف‌شده ناشی از privacy به کل سایت تعمیم داده نشوند.
