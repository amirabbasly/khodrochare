# تفکیک وضعیت ایندکس و وضعیت فنی

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## ثبت تصمیم و وضعیت

| مورد | نتیجه |
|---|---|
| مشکل | GSC/Bing/Yandex URL status در دسترس نیست |
| شواهد | inventory 512 مسیر از کد و آزمون تولیدی؛ sitemap local 475 URL |
| شدت | P1 برای نیاز داده؛ P0 محلی مشاهده نشد |
| اثر تجاری | نبود ایندکس می‌تواند مانع ورودی باشد اما هنوز علت اثبات نشده |
| راه‌حل | نگاشت technicalClass به URL inspection واقعی هر موتور |
| اقدام انجام‌شده | CSV کامل با ستون indexStatus=unknown_requires_webmaster ساخته شد |
| نتیجه تست | 475 indexable؛ 4 noindex؛ 15 redirect؛ 18 invalid-test 404 |
| وضعیت نهایی | indexability محلی معلوم؛ indexing موتور نامعلوم |

## دسته‌بندی
- Indexable: HTTP200، بدون noindex و canonical self نرمال؛ به معنی indexed نیست.
- Noindex: store/friday-market/car-market/imports عمداً؛ تغییر داده نشد.
- Redirected: 15 alias شناخته‌شده؛ canonical destination و chain تست می‌شود.
- 404: 18 URL آزمایشی ساختگی در inventory علامت‌دارند؛ گزارش خطای واقعی تولید محسوب نشوند.
- 410، blocked، duplicate و canonicalized غیرself: در مجموعه بررسی‌شده نمونه قطعی ثبت نشد؛ وضعیت کل اینترنت/edge را نتیجه نمی‌دهد.
- Crawled not indexed / Discovered not indexed: نیازمند گزارش خود موتور؛ از HTTP یا sitemap استنباط نشوند.

## Sitemap
475 URL canonical با تصاویر در sitemap؛ زیر حد نیاز به تقسیم است. noindex، redirect و API در آن نیستند. 87 تاریخ بعد از مرجع 2026-10-17 برای بازبینی علامت خوردند. آخرین‌تغییرهای hardcoded آینده با تاریخ build جایگزین نشدند. در صورت نبود تاریخ معتبر حذف lastmod بهتر از تاریخ فرضی است؛ قبل از تغییر، تاریخ انتشار/اصلاح واقعی باید تأیید شود.

## عملیات
ابتدا deploy موردنظر، سپس fetch robots/sitemap/canonical روی دامنه و inspection نمونه‌های تجاری در سه موتور؛ screenshot وضعیت و تاریخ crawl. ارسال sitemap یک‌بار و بعد تغییر معنی‌دار؛ URL Inspection یا IndexNow تضمین ایندکس نیست. Google Indexing API برای مقاله/خدمت عمومی استفاده نشود.
