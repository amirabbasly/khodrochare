# گراف لینک داخلی

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## ثبت تصمیم و وضعیت

| مورد | نتیجه |
|---|---|
| مشکل | نیاز به depth و inbound واقعی در build، نه حدس از منو |
| شواهد | SEO_URL_INVENTORY.csv ستون crawlDepth و internalInboundPages؛ script گراف HTML |
| شدت | P2 |
| اثر تجاری | دسترسی به landing درآمدزا و crawl depth |
| راه‌حل | تعیین صفحه مرجع intent و حفظ لینک زمینه‌ای |
| اقدام انجام‌شده | گراف از anchorهای HTML استخراج شد؛ لینک نامرتبط انبوه اضافه نشد |
| نتیجه تست | هیچ صفحه indexable در گراف بررسی‌شده از خانه unreachable نیست |
| وضعیت نهایی | محلی پاس؛ گراف live و بک‌لینک خارج ریپو نامعلوم |

## روش
BFS از `/` روی hrefهای داخلی همان origin؛ لینک self برای inbound شمرده نشده؛ شمارنده inbound تعداد صفحه منبع است، نه تعداد تکرار لینک. لینک query به pathname نرمال می‌شود؛ لینک وابسته به تعامل غیر href در گراف نیست. Footer می‌تواند depth را کم کند؛ این به معنی link equity بالا یا کیفیت انکر نیست.

## قواعد آینده
- صفحه شهر → خدمت همان شهر فقط اگر پوشش و محتوای مرتبط دارد.
- مقاله → خدمت/ابزار متناسب با تصمیم؛ لینک «امداد خودرو تهران» در هر پاراگراف اضافه نشود.
- آنلاین ↔ app با دو هدف جدا؛ نصب اپ نباید به معنی ثبت درخواست معرفی شود.
- صفحه قیمت ↔ ابزار حمل با توضیح فرمول و محدودیت؛ برآورد، قیمت قطعی نیست.
- noindex بازارها حفظ و در sitemap قرار نگیرند؛ دکمه ناوبری قابل مشاهده برای کاربر الزاماً صفحه SEO نیست.

## کنترل
`npm run test:seo` مقصدهای داخلی و anchorها، تصاویر، metadata و reachable بودن routeها را تست می‌کند. `npx tsx scripts/seo-inventory.ts` خروجی قابل مقایسه پس از build می‌سازد. crawl عمومی تمام لینک‌های تاریخی بیرون از سورس هنوز لازم است.
