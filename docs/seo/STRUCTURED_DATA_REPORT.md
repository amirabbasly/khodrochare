# بررسی داده ساختاریافته

> **به‌روزرسانی پس از تأیید مالک:** کاربر جایگزینی کامل نام حقوقی با «سیما رایگان ایرانیان» و تعلق مجوز، مدیرعامل و نشانی فعلی به همین شرکت را صریحاً تأیید کرد. نام مرکزی و متن‌های ثابت مجوزها/درباره اصلاح شده‌اند و Schema و سایر مصرف‌کنندگان از همان منبع تغذیه می‌شوند. این تأیید مالک است، نه استعلام مستقل ثبتی؛ شناسه ملی یا شماره ثبت جدیدی اضافه نشد. عبارت‌های «تعارض باز/مسدود» مربوط به هویت در بدنه زیر، یافته تاریخی پیش از تأییدند و وضعیت جاری آن‌ها **رفع‌شده در کد بر اساس تأیید مالک** است. سایر کمبودهای داده/حساب و تاریخ‌ها همچنان بازند.


> تاریخ مرجع تحلیل: 2026-10-17. شواهد فنی: production build محلی؛ مشاهده عمومی سایت جدا از آزمون محلی است. داده حسابی موتورهای جست‌وجو در دسترس نیست. «قابل ایندکس» به معنی «ایندکس‌شده» نیست. زمان ثبت ابزارها ممکن است با تاریخ مرجع متفاوت باشد؛ در inventory ستون dateReview موارد بعد از تاریخ مرجع را مشخص می‌کند.

## ثبت تصمیم و وضعیت

| مورد | نتیجه |
|---|---|
| مشکل | صحت JSON کافی نیست؛ واقعیت حقوقی/کسب‌وکار باید تأیید شود |
| شواهد | src/seo/schemas.ts؛ src/components/seo/*؛ ستون schema در inventory |
| شدت | P1 برای هویت؛ P2 برای type eligibility |
| اثر تجاری | اطلاعات نادرست ممکن است پاسخ و اعتماد را خراب کند |
| راه‌حل | تطبیق با متن و نوع کسب‌وکار واقعی، بدون رتبه/نظر جعلی |
| اقدام انجام‌شده | JSON-LD تمام صفحات local parse شد؛ Schema جدید بی‌مدرک اضافه نشد |
| نتیجه تست | تست parse و قواعد پروژه پاس؛ Rich Results/validatorهای آنلاین اجرا نشدند |
| وضعیت نهایی | syntax محلی پاس؛ semantic و engine validators باز |

## موجودیت‌های فعلی
Organization پایه با typeهای LocalBusiness/AutoRepair در schema موجود، WebSite، WebPage، Service، Breadcrumb، Article و FAQ در خانواده‌های مختلف. فهرست دقیق type هر URL در CSV است. AutoRepair/LocalBusiness برای پلتفرم هماهنگی باید با مدل واقعی و آدرس تأییدشده سنجیده شود؛ تبدیل کور به Organization بدون بازبینی انجام نشد.

## تصمیم‌های محافظه‌کارانه
- Person، MobileApplication یا aggregateRating جدید ساخته نشد. PWA واقعی الزاماً APK منتشرشده یا قیمت app ندارد.
- نبود FAQ rich result به معنی خراب بودن پاسخ‌های قابل مشاهده نیست. URL رسمی FAQ گوگل هنگام بازبینی به updates#removing-faq-rich-result هدایت شد؛ برای کسب‌وکار امداد، وعده FAQ rich result داده نشد و محتوای FAQ مفید حذف نشد.
- @id ثابت و logo واقعی برند حفظ شد؛ شرکت جدید تا رفع تعارض به مجوز/مدیر قبلی نسبت داده نشد.
- قیمت ابزار تخمینی به offers با قیمت قطعی تبدیل نشد؛ آمار hero به Review/Rating جعلی تبدیل نشد.

## مرحله بعد
با نمونه خانه، آنلاین، خدمت، شهر و مقاله در validatorهای در دسترس هر موتور بررسی کنید؛ برای هر نتیجه URL، تاریخ و خطا/هشدار واقعی ذخیره شود. تأیید خود Schema.org به معنی شرایط rich result همه موتورها نیست. تست داخلی اکنون ضمانت معنایی همه ادعاهای سایت نیست.
