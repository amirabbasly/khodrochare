# مرحله نهایی سئو — انتشار نظرات واقعی، محله‌های رشت و تکمیل لینک‌سازی داخلی

تاریخ: ۱ مهر ۱۴۰۵ (۲۰۲۶-۰۹-۲۳) — دنباله `docs/seo-authority-2026-09-23.md`

## خلاصه

- انتشار ۶ نظر واقعی مشتری (متن، نام، خدمت، محله، تاریخ شمسی/میلادی) در داده‌ها،
  کارت‌های صفحه و اسکیما — بدون دست بردن در چیدمان صفحه اصلی.
- فعال شدن `aggregateRating` سازمان با گیت «حداقل ۵ نظر» + گارد ممیزی که هر
  امتیاز تجمیعی ضعیف را در استقرار production مردود می‌کند.
- افزودن ۳ صفحه محله رشت (گلسار، معلم، منظریه) → **۴۱۹ مسیر ایندکس‌پذیر**
  (از ۴۱۶) با لینک خودکار از صفحه شهر رشت.
- بستن شکاف لینک ورودی هایما (صفر لینک → ۲ لینک) و تقویت فیدلیتی.
- مستندات عملیات سرچ کنسول برای مالک: `docs/google-search-console.md`.

- هر نظر هم در کارت قابل مشاهده است هم در `Review` JSON-LD (شرط ممیزی: تطابق

- تیتر نظر (`h3`) به کارت‌ها اضافه شد — افزودنی متنی، بدون تغییر چیدمان.
- `reviewSchema` حالا `name` را از تیتر می‌سازد تا ریچ‌رزالت معنادارتر شود.

## ۲ — امتیاز تجمیعی سازمان (`src/seo/schemas.ts`)

- `aggregateRating` فقط وقتی منتشر می‌شود که حداقل ۵ نظر واقعی وجود داشته باشد؛
  با ۶ نظر پنج‌ستاره: `ratingValue: 5 ، reviewCount: 6`.
- گارد تازه در `scripts/check-production-seo.ts`: هر `aggregateRating` با
  `reviewCount < 5` یا مقدار نامعتبر، ممیزی production را قرمز می‌کند.
- شماره تماس قدیمی و ناسازگار (`+989397979861`) از اسکیما حذف و با خط یکپارچه
  `۰۹۳۹۷۹۷۹۸۶۱` جایگزین شد.

## ۳ — محله‌های رشت (`src/content/neighborhoods.ts`)

- گلسار، معلم، منظریه — هرکدام با راهنمای اعلام نشانی، مختصات باران/آب‌گرفتگی
  رشت و سناریوی خرابی. صفحه شهر رشت به‌صورت خودکار به هر سه لینک می‌دهد.
- آدرس‌ها: `/رشت/گلسار`، `/رشت/معلم`، `/رشت/منظریه`.

## ۴ — لینک‌سازی داخلی (بستن شکاف‌ها)

- راهنمای هایما S7 صفر لینک ورودی داشت → لینک از صفحه خدمت کفی + راهنمای چانگان.
- فیدلیتی → لینک تازه از راهنمای KMC.
- سیاست حفظ‌شده: هر راهنما حداقل یک لینک ورودی معنادار از بدنه محتوای مرتبط.

## ۵ — اعتبارسنجی (همه سبز)

- `npm run test:unit` → **۴۲/۴۲** (تست تازه: صحت ۶ نظر + تطابق اسکیمای تجمیعی).
- `npm run typecheck` → سبز. `npm run lint` → سبز.
- `npm run build` → موفق (صفحه اصلی دست‌نخورده؛ فقط یک سطر تیتر در کارت نظر).
- `npm run test:seo` → ۴۱۹ صفحه مورد انتظار، ۴۲۰ بررسی‌شده، **۰ خطا**.
- `npm run indexing:export` → ۴۱۹ URL متعارف (شامل ۳ محله رشت).
- تست مرورگری (`test:browser`) مثل دوره‌های قبل در سندباکس اجرا نشد (نیاز به
  کرومیوم واقعی) و به CI سپرده شد.
