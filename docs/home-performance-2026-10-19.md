# سبک‌سازی لندینگ بدون بازطراحی — 2026-10-19

## تغییرات

- بخش مجله فقط ۱۰ مقاله جدید را با مرتب‌سازی نزولی `publishedAtIso` نمایش می‌دهد. ویرایش یک مقاله قدیمی آن را به بالای فهرست نمی‌برد؛ برای تاریخ‌های برابر slug ترتیب قطعی می‌دهد.
- به‌جای ارسال تمام بدنه ۶۷ مقاله به Client Component، فقط شش فیلد لازم کارت‌ها ارسال می‌شود: slug، title، excerpt، category، readTime، image. payload این props از ۵۷۶٬۹۱۹ بایت به ۵٬۹۳۴ بایت کاهش یافت (حدود ۹۹٪).
- پنج کارت اول در HTML اولیه موجودند؛ پنج کارت دوم فقط پس از انتخاب «بعدی» mount می‌شوند. ابعاد grid، کارت‌ها، کنترل‌های قبل/بعد و لینک آرشیو بدون تغییر مانده‌اند. اسلاید غیر‌فعال inert و از دسترس صفحه‌خوان خارج است.
- داده منو از پروفایل‌های کامل فنی برند و منطقه جدا شد؛ مرورگر فقط نام، slug و نام لاتین برندها و نام/slug مناطق را دریافت می‌کند. تست تطبیق با منابع canonical مانع ناهماهنگی آینده است.
- prefetch خودکار شبکه برای فهرست ۵۹ لینک محلی، کارت‌های مجله، نوار لوگوها و لینک‌های مگامنو غیرفعال شد؛ href واقعی، کلیک، ناوبری و قابلیت خزش حفظ شده‌اند.
- خروجی on-demand تصاویر به WebP محدود شد تا CPU تولید AVIF پس از کش سرد مصرف نشود. تصاویر، نسبت‌ها، sizes، کیفیت‌های تعریف‌شده و lazy loading حفظ شدند. این تغییر تنظیمی سراسری است؛ در بعضی تصاویر WebP ممکن است از AVIF حجیم‌تر باشد، اما هزینه encode پایین‌تر است.
- بخش‌ها، انیمیشن‌های یدک‌کش و نوار برند، ظاهر شیشه‌ای، بنرها، منوی click-only، نصب PWA، لینک‌های داخلی و محتوای سئو حذف یا بازطراحی نشدند.

## اندازه‌گیری قبل/بعد

خروجی HTML بیلد Production یک مسیر ثابت (`/`) با شمارش Cheerio و gzip محلی؛ این اعداد اندازه‌گیری CPU یا Core Web Vitals سرور واقعی نیستند:

| معیار | قبل | بعد | کاهش |
|---|---:|---:|---:|
| HTML اولیه، بایت | 1,242,167 | 509,774 | 58.96% |
| همان HTML با gzip محلی، بایت | 191,597 | 62,772 | 67.24% |
| تگ‌های تصویر در HTML اولیه | 117 | 55 | 62 تگ کمتر |
| همه تگ‌های لینک در HTML اولیه | 356 | 294 | فقط کارت‌های آرشیوی اضافی حذف شدند |

اسناد خام اندازه‌گیری و تصاویر بازبینی در `coverage/performance/` هستند و وارد Git نمی‌شوند. باقی‌ماندن ۵۵ تگ تصویر به معنی دانلود فوری همه آن‌ها نیست؛ lazy loading برقرار است.

## بررسی کیفیت

- lint بدون هشدار، ۹۹ تست واحد و production build موفق.
- ممیزی production SEO: ۴۷۲ صفحه indexable، ۴۷۳ صفحه بررسی‌شده، صفر خطا؛ تمام صفحات indexable از لینک‌های داخلی قابل دسترسی‌اند. آرشیو کامل مقالات در `/blog` و خود صفحات مقالات باقی مانده است.
- تست تازه مرورگر: ترتیب جدیدترین کارت‌ها، mount پنج کارت اول، جابه‌جایی و برگشت اسلایدر، نبود overflow و حفظ ۵۹ لینک محلی و نبود prefetch آن‌ها.
- بازبینی تصویر دسکتاپ و موبایل؛ بارگیری موفق هر پنج تصویر اسلاید اول تأیید شد.
- اجرای کامل مرورگر دسکتاپ و موبایل: ۱۵۲ موفق، ۲ skipped، صفر شکست (۴٫۷ دقیقه). تست‌های منو، حرکت پیش‌فرض یدک‌کش/نوار، نصب وب‌اپ، هندسه بنرها، صفحات محتوا و کنترل‌های جدید اسلایدر موفق بودند.

## انتشار و محدودیت تشخیص CPU

خروجی `ps` ارسالی مالک، میانگین CPU عمر پردازش را نشان می‌دهد و جهش لحظه‌ای ۸۵٪ را تأیید یا رد نمی‌کند. این تغییرات یک عامل پرهزینه تصویر و اضافه‌بار قابل اندازه‌گیری لندینگ را کاهش می‌دهند؛ کاهش مشخص CPU روی سرور واقعی یا رفع تمام علت‌های کندی تضمین نشده است.

برای انتشار: pull همین branch، `npm ci --include=dev`، `npm run build` و restart سرویس موجود. کش `.next/cache/images` را در انتشارهای بعدی بی‌دلیل پاک نکنید؛ با توجه به روش استقرار، ماندگاری آن باید در زیرساخت مدیریت شود. در این تغییرات تنظیم PM2 یا Nginx سرور واقعی دستکاری نشده است.
