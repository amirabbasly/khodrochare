# گزارش نسخه: توسعه پوشش و سئوی خودرو چاره

**محدوده این گزارش، کد و آزمون production در محیط آزمایش است؛ نه تأیید استقرار روی دامنه اصلی و نه تأیید ایندکس گوگل.** استقرار سرور طبق درخواست به عهده مالک سایت است. نتیجه GitHub Actions باید در PR مربوط بررسی شود؛ آزمون‌های محلی زیر پیش از push انجام شده‌اند.

## چه چیزی اضافه یا اصلاح شد؟

- پوشش داده و صفحات برای تهران، کرج و شبکه فعال **گیلان، مازندران و گلستان**؛ بدون ساخت آدرس شعبه، زمان رسیدن یا تعرفه تأییدنشده.
- **۲۶ صفحه شهر، ۳ صفحه استان، صفحه شمال، ۴۲ صفحه محله/محدوده، ۱۲ صفحه برند و ۵ صفحه محور**، با صفحات فهرست و خدمات مرتبط.
- دو راهنمای متمایز برای «امداد خودرو» و «امداد خودرو آنلاین»: اولی برای انتخاب خدمت، دومی برای اطلاعات لازم، وضعیت پذیرش و مراحل هماهنگی.
- متن محلی برای دسترسی، پارکینگ، مسیر و تحویل؛ نکات برند متناسب با مدل/گیربکس/باتری/حمل و تصریح مستقل‌بودن خدمات از نمایندگی خودروسازان.
- حفظ تمام **۶۵ URL هدف نسخه پایه**. اکنون **۳۷۴ URL در sitemap** وجود دارد؛ ۳۰۹ مورد بیشتر از پایه. تعداد URL تضمین ارزش یا ایندکس نیست.
- canonical و متادیتای یکتا، breadcrumb، Service/Organization/WebPage/FAQ و لینک داخلی قابل خزیدن؛ نبود صفحه یتیم در گراف بررسی‌شده.
- اصلاح اشتباه ترکیب شهر و منطقه، از جمله `/کرج/شمال-تهران`، و ۱۵ ریدایرکت مشخص قدیمی. مسیر نامعتبر به صفحه اصلی فرستاده نمی‌شود.
- رفع دو مشکل واقعی مسیر فارسی: prerender پوشه ثابت غیرلاتین در نسخه فعلی Next، و پارامترهای percent-encoded که می‌توانستند با وجود build موفق، خروجی ۴۰۴ تولید کنند.
- اصلاح پوشش و ادعاهای زمان/آمار در قالب‌های فعال، تثبیت H1 صفحه اصلی هنگام تغییر اسلاید، لینک‌شدن برندها و به‌روزرسانی navigation/FAQ.
- لینک بله در خروجی صفحات و هویت کسب‌وکار: **https://ble.ir/join/G627cQxSZD**.
- سیاست خزنده‌های جست‌وجو مستقل از آموزش مدل‌ها؛ استثنای `/api/` در گروه‌های صریح robots نیز تکرار شده است.
- فرم با fallback تلفنی، API پذیرش اختیاری، اعتبارسنجی، محدودسازی درخواست، سقف بدنه، timeout و قرارداد تأیید؛ رویداد تحویل فقط پس از تأیید واقعی API.
- ابزار هزینه در `/pricing`، با اعداد فارسی و محاسبه صرفاً از **نرخ‌های واردشده توسط کاربر**؛ بدون عددسازی تعرفه یا تخمین فاصله GPS.
- راهنمای واقعی نسخه وب/PWA و صفحه آفلاین؛ API و داده فرم وارد cache یا صف ارسال آفلاین نمی‌شوند.
- آزمون‌های تکرارپذیر و workflow GitHub، به همراه فهرست کامل URLهای مناسب ثبت sitemap.

## مرزهای مهم انتشار

1. **سرور اصلی deploy نشده است.** پس از دریافت این کد، build/restart و بررسی CDN/HTTPS با مالک سرور است.
2. **پذیرش واقعی به اتصال نیاز دارد.** بدون `SERVICE_REQUEST_WEBHOOK_URL` معتبر، فرم تنها اطلاعات تماس آماده می‌کند. تست موفقِ mock به معنی آماده‌بودن مقصد واقعی کسب‌وکار نیست.
3. **تعرفه عددی مصوب ارائه نشده است.** ابزار قیمت، نرخ شما را جمع می‌زند؛ نقشه مسافت یا قیمت رسمی ارائه نمی‌کند.
4. **رتبه، backlink، سرعت واقعی یا ایندکس اندازه‌گیری/تضمین نشده‌اند.** نتایج فنی محلی جای داده Search Console، CrUX یا وضعیت سرور زنده نیستند.
5. **Cloudflare/WAF مستقل است.** robots نهایی و مجازبودن دریافت محتوا توسط موتورهای جست‌وجو باید پس از استقرار کنترل شوند.
6. **سامانه کارگاهی/اعزام کامل ساخته نشده است.** این تغییر، سایت محتوا، ابزار، فرم و رابط انتقال به پذیرش را تکمیل می‌کند؛ پنل سفارش، پرداخت، حساب کاربری و ردیابی زنده خارج از آن‌اند.
