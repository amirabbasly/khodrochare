# راهنمای سرچ کنسول برای تغییرات اخیر خودرو چاره

## ۱. ثبت مالکیت (فقط بار اول)
- در https://search.google.com/search-console/ گزینه Add property را بزنید.
- پیشنهاد: Domain با مقدار `khodrochare.ir` (بدون https و مسیر).
- رکورد TXT تولیدشده توسط خود گوگل را عیناً در DNS دامنه وارد کنید. مقدار نمونه یا ساختگی استفاده نکنید. سپس Verify را بزنید؛ انتشار DNS ممکن است زمان ببرد.
- اگر دسترسی DNS ندارید، URL-prefix با `https://khodrochare.ir/` و یکی از روش‌های واقعی تأیید گوگل را انتخاب کنید. تگ یا فایل تأیید باید در انتشارهای بعدی حفظ شود.
- رمز، توکن یا دسترسی حساب را در چت ارسال نکنید. اگر مالکیت قبلاً تأیید شده، نیازی به property جدید نیست.

## ۲. پس از انتشار واقعی تغییرات
پوش گیت به‌تنهایی اثبات انتشار روی دامنه نیست. اول نسخه زنده را بررسی کنید:
- صفحه با پاسخ 200 باز شود و noindex نداشته باشد.
- canonical به نسخه HTTPS همان صفحه اشاره کند؛ URL canonical را برای بررسی انتخاب کنید.
- بخش دانلود اپ در ابتدای صفحه امداد آنلاین دیده شود؛ لینک مایکت، بازار، PWA و تماس درست باشند.
- مسیرهای موقت بازار/واردات ممکن است عمداً noindex باشند؛ برای گرفتن ایندکس آن‌ها اصرار نکنید.

## ۳. نقشه سایت
در بخش Sitemaps این آدرس را ثبت کنید:
`https://khodrochare.ir/sitemap.xml`
اگر قبلاً ثبت و Success شده، حذف و ثبت مجدد روزانه لازم نیست. تاریخ آخرین خواندن و خطاهای دریافت را بررسی کنید.

## ۴. URL Inspection برای صفحات مهم تغییرکرده
به‌ترتیب اولویت، آدرس‌های زیر را در نوار URL Inspection بررسی کنید:
1. `https://khodrochare.ir/امداد-خودرو-آنلاین`
2. `https://khodrochare.ir/app`
3. `https://khodrochare.ir/safir`
4. `https://khodrochare.ir/assistant`
5. `https://khodrochare.ir/`

برای هر کدام Test live URL را بزنید؛ در View tested page، HTML و تصویر رندرشده را ببینید. امکان crawl، وضعیت indexing و canonical را بررسی کنید. پس از انتشار و نبود خطای مانع، Request indexing را یک بار بزنید. اگر سهمیه تمام شد، منتظر بمانید؛ درخواست مکرر اولویت یا رتبه تضمین نمی‌کند. این کار برای تک‌تک صفحات سایت لازم نیست.

## ۵. پایش نتیجه
- در Performance > Search results، فیلتر Page را روی URL دقیق صفحه امداد آنلاین بگذارید.
- Queryهای «امداد خودرو آنلاین»، «درخواست امداد خودرو»، «یدک کش آنلاین» و عبارت‌های خدمات/شهر را بررسی کنید.
- کلیک، impression، CTR و average position را برای بازه‌های ۲۸ روزه مقایسه کنید؛ دستگاه موبایل و دسکتاپ را جدا ببینید. تغییرات فصلی و حجم کم داده می‌توانند مقایسه را منحرف کنند.
- در Pages، علت‌های عدم ایندکس و canonical انتخاب‌شده گوگل را بررسی کنید؛ هر Excluded الزاماً خطا نیست.
- در Core Web Vitals، داده میدانی موبایل را بررسی کنید؛ نتیجه build یا Lighthouse جای داده واقعی کاربران را نمی‌گیرد.
- رتبه متوسط یک query اثبات رتبه بالاتر از یک رقیب برای همه کاربران نیست. ثبت تغییر، تاریخ انتشار واقعی و مقایسه روند از وعده رتبه معتبرتر است.

## محدودیت‌ها
این راهنما به معنی ثبت property، ارسال نقشه سایت، درخواست ایندکس یا تأیید انتشار نیست. برای این موارد دسترسی مالک لازم است. FAQ در صفحه برای کاربر مفید است اما نمایش نتیجه غنی گوگل تضمین‌شده نیست. برای مقالات و لندینگ معمولی از Indexing API سوءاستفاده نکنید.
