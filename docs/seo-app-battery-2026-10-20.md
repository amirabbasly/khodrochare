# اتصال اپلیکیشن، بازآرایی محتوا و بخش برق و باتری

تاریخ بررسی و تغییر: ۲۰ اکتبر ۲۰۲۶ / ۲۸ مهر ۱۴۰۵. این گزارش تغییرات کد و مشاهده عمومی صفحات را ثبت می‌کند؛ بهبود رتبه یا افت تاریخی را بدون داده Search Console اثبات نمی‌کند.

## تغییرات واقعی

- لینک اصلی مشتریان `https://app.khodrochare.ir/` و ناوگان `https://safir.khodrochare.ir/` در یک فایل مرجع تعریف شده است. دکمه‌های نصب/درخواست به محصول اصلی می‌روند؛ `/app` راهنمای دو مخاطب و نصب نسخه وب است، نه نصب سایت معرفی. CTAهای خدمات و مقالات هم به اپ متصل‌اند.
- صفحه آنلاین با موضوع «ورود، درخواست و هماهنگی خدمت» بازنویسی شده؛ فرم قدیمی غیرفعال از آن حذف شده است. API و کامپوننت قدیمی حذف نشده‌اند تا قراردادهای قبلی بی‌دلیل شکسته نشوند؛ اکنون مسیر اصلی مشتری نیستند. تست‌های مرورگر مقصد لینک و عدم تماس با API قدیمی را می‌سنجند و هیچ سفارش واقعی به اپ نمی‌فرستند.
- عنوان و H1 صفحه اصلی روی خدمات و پوشش، صفحه آنلاین روی فرایند درخواست و `/app` روی ورود/نصب تفکیک شده‌اند. هیچ canonical یا redirect حدسی برای حذف صفحات اعمال نشده است.
- `/licenses` بدون تصویر مدرک بازنویسی شده: شرکت پیشرو امدادگران هوانیروز، برند ثبتی خودرو چاره، جواز یکتا و فعالیت کشوری امداد خودرو، مدیرعامل علیرضا سلیمانی. معرفی، طبق اعلام مجموعه است؛ شماره، مرجع صادرکننده، تاریخ اعتبار یا لینک استعلام ساخته نشده است. اطلاعات هویتی در درباره ما، پانوشت و schema سازمان نیز هماهنگ شده‌اند. عکس معرفی خدمت، تصویر جواز نیست.
- `/battery` هاب مستقل برق و باتری است: تفکیک علائم، تست شارژ/استارت، انتخاب فناوری و قطعه، ضمانت و هزینه، ایمنی هیبرید و نکات اختصاصی ۱۲ برند از جمله ایران خودرو. این هاب کپی صفحه تعویض باتری نیست؛ صفحات خدمات تست/تعویض، باتری‌به‌باتری و دیاگ intent اجرایی خود را نگه داشته‌اند. لینک‌های رفت‌وبرگشت برندها، خدمات، مناطق، منو و پانوشت اضافه شده‌اند؛ مسیر در sitemap و inventory ثبت شده است.
- ۱۲ صفحه عمومی برند: لایه توسعه متنی تکراری از render حذف شده؛ راهنمای مدل‌ها در صفحه عمومی باقی است. در ۳۶ صفحه برند×منطقه، راهنمای کامل مدل، تشخیص و حمل کپی نمی‌شود؛ دسترسی منطقه، سناریوی توقف، مقصد و تحویل محور محتواست و راهنمای فنی با لینک ارجاع داده می‌شود. این بازآرایی کاهش واقعی متن تکراری است، نه افزودن مترادف و کلمه.
- ۵ صفحه محور: از سه لایه توسعه هم‌پوشان به یک لایه اختصاصی مسیر رسیده‌اند. یادداشت‌های مسیر کوتاه و عملی بازنویسی شده و هر محور یک FAQ اختصاصی، علاوه بر پرسش‌های پایه، دارد. ادعاهای بی‌منبع «پرترافیک‌ترین/بهترین شهر تعمیر» و توصیه حرکت خودروی معیوب برای رسیدن به محل ملاقات حذف شده‌اند. تست حداقل کلمه جای خود را به کنترل پوشش مسیر و نبود بدنه تکراری داده است.
- متن‌های قدیمی درباره «فقط خلاصه تماس و نبود پذیرش» در راهنمای آنلاین مقالات، FAQ و حریم خصوصی با مسیر محصول جداگانه هماهنگ شده‌اند. درباره نگهداری داده در اپ مستقل تعهد تأییدنشده داده نشده است.
- ساختار مگامنوی کلیکی، مدل‌ها و صفحات عمیق، موشن پیش‌فرض، نوار برندها، شیشه‌ای‌بودن لندینگ و محدودبودن بخش مقالات حفظ شده‌اند.

### منابع و محدودیت‌ها

1. `https://emdadyar24.com/` — صفحه اصلی در این نوبت خوانده شد: اپ مستقیم، تلفن، خدمات، برندها، مناطق تهران، هزینه و راهنماها. مشاهده صفحه اصلی جای crawl کامل سایت نیست. ادعای انتخاب خودکار نزدیک‌ترین تکنسین صرفاً متن رقیب است، نه نتیجه تست مستقل.
2. `https://emdadekhodro.com/` و `https://www.emdadekhodro.com/` — درخواست مستقیم ابزار در این نوبت HTTP 500 داشت. فقط نتیجه جست‌وجوی `site:emdadekhodro.com امداد خودرو باتری آنلاین` برای مقایسه محدود استفاده شد؛ این نتیجه ممکن است قدیمی باشد. HTTP 500 ابزار به معنی خرابی دائمی سایت برای تمام کاربران نیست. نبود اپ، نبود هاب باتری یا برتری کامل ما نسبت به این رقیب نتیجه‌گیری نمی‌شود.
3. `https://app.khodrochare.ir/` و `https://safir.khodrochare.ir/` — صفحه عمومی ورود و ثبت‌نام مشاهده شد. پشت ورود، ارسال سفارش، رهگیری، GPS، اعزام خودکار و APK بررسی نشده‌اند؛ تست این مخزن هم آن قابلیت‌ها را تأیید نمی‌کند.

**نتیجه:** ساختار جدید از نظر تفکیک هدف صفحات، ارتباط محتوا و مسیر تبدیل روشن‌تر شده است. نسبت به الگوی صفحه اصلی امدادیار۲۴، CTA محصول اکنون مستقیم است و محور برق/باتری عمق مستقلی دارد؛ این مزیت ساختاری محلی، اثبات برتری کل سایت یا رتبه گوگل نیست. درباره رقیب دوم داده زنده کافی برای چنین حکمی وجود ندارد.

## کارهای نیازمند تأیید خارج از کد

- تلفن عمومی دو اپ `02191855` با تلفن سایت معرفی `09123022064` متفاوت مشاهده شد. شماره سایت خودسرانه عوض نشده؛ مدیریت باید نقش هر خط و متن پشتیبانی را تأیید کند.
- جزئیات شماره و استعلام جواز، در صورت تصمیم مدیریت، باید از مرجع واقعی ارائه شوند؛ تصویر مدرک بنا به درخواست درج نشده است.
- برای سنجش اثر، پس از deploy در GSC صفحه‌های `/`، آنلاین، `/app`، `/battery` و گروه برند/منطقه را جدا کنترل کنید: index/canonical و سپس clicks/impressions/CTR و queryهای هم‌پوشان. بدون تاریخ افت و داده قبل/بعد، علت افت معلوم نیست. کاهش کلمات تکراری ممکن است طول صفحات را کم کند؛ تعداد کلمه KPI موفقیت نیست.
- push به مخزن معادل deploy و نتیجه رتبه نیست. سفارش واقعی و حریم خصوصی اپ باید در محیط محصول توسط صاحب حساب بررسی شوند.

## کنترل کیفیت

نتایج نهایی اجرای تست‌ها در انتهای این گزارش ثبت می‌شوند.

### نتیجه نهایی اجرا

- `npm run lint`: موفق، بدون هشدار و خطا.
- `npm run test:unit`: **۱۰۴ تست موفق**.
- `npm run build`: موفق، شامل TypeScript و تولید صفحات استاتیک.
- `npm run test:seo`: **۴۷۳ مسیر قابل ایندکس / ۴۷۴ صفحه بررسی‌شده، صفر خطا**؛ همه مسیرهای قابل ایندکس از لینک‌های داخلی قابل دسترسی‌اند. ۱۸ مسیر نامعتبر و ۱۵ ریدایرکت قدیمی نیز کنترل شدند.
- `npm run test:browser`: **۱۵۶ موفق، ۲ skipped** در دسکتاپ و موبایل. مقصد اپ‌ها در تست mock شده و سفارش واقعی ارسال نشده است. تست‌های موشن پیش‌فرض، مگامنوی کلیکی، نمایش برندها، overflow، هیدریشن و سبک‌سازی لندینگ موفق‌اند.
- `git diff --check`: موفق.
- شکست اولیه دو تست ناشی از دو لینک عمومی یکسان در صفحه منطقه‌ای بود؛ لینک تکراری از خود صفحه حذف و کل مجموعه مرورگر دوباره با موفقیت اجرا شد.

خروجی حجیم build، تصاویر تست، مرورگر و وابستگی موقت تست به Git اضافه نشده‌اند. اسکریپت‌های ممیزی، گزارش کامل ماشین‌خوان را زیر `coverage/seo/production-report.json` تولید می‌کنند (ignored).
