# توسعه محتوا و ابزارهای امداد خودرو — ۱۶ شهریور ۱۴۰۵

این نسخه به جای تغییر ظاهر یا تولید انبوه صفحات مشابه، بر انتخاب خدمت، هزینه حمل، تایر، دیاگ و راهنمای هماهنگی تمرکز دارد. آمار خصوصی ارسالی مالک از Search Console داخل مخزن یا صفحات عمومی منتشر نشده است.

## دامنه تغییرات

- **سه ابزار تازه و مرکز ابزارها**:
  - `/tools`
  - `/tools/transport-selector`: پرسش‌های روش حمل، گیربکس، محور محرک، چرخ و دسترسی؛ با خروجی محافظه‌کارانه برای مجهولات.
  - `/tools/breakdown-guide`: اول ایمنی، سپس مسیر بررسی؛ پاسخ به وضعیت اضطراری بدون انتظار برای تکمیل سایر پرسش‌ها ظاهر می‌شود.
  - `/tools/obd-code`: معنی ۱۲ کد عمومی، حدود تفسیر و منابع؛ نه اتصال به خودرو یا تشخیص قطعی.
- **ارتقای `/pricing`**: عنوان و پیوندهای متناسب با محاسبه هزینه حمل با کفی و یدک‌کش، مقایسه دو برآورد هم‌دامنه در `#compare-quotes` و جلوگیری از ارسال ناخواسته فرم بدون JavaScript.
- **مقایسه قیمت صرفاً حساب است**: نرخ بازار، تعرفه رسمی، مسیر جاده‌ای، کیفیت ارائه‌دهنده یا بیمه حدس زده نمی‌شود. ورودی‌های نامعتبر و جداکننده مبهم مثل `1,5` رد می‌شوند.
- **شش مقاله جدید** و بازنویسی هشت مقاله قبلی؛ تعداد مقالات **۲۴** شده است. تاریخ انتشار مقالات قبلی حفظ و تاریخ ویرایش فقط برای محتوای واقعاً اصلاح‌شده تغییر کرده است.
- توسعه **هفت صفحه خدمت**، **سه صفحه محلی هدفمند** و **دو صفحه اصلی موضوعی** با چک‌لیست، پاسخ روشن و پیوند ابزارهای مرتبط.
- پاسخ‌های FAQ در متن و schema هماهنگ‌اند. منابع قابل مشاهده مقاله‌ها در داده ساختاریافته نیز منعکس می‌شوند؛ نویسنده متخصص، تجربه عملی یا امتیاز ساختگی اضافه نشده است.
- فهرست canonical از **۳۷۴ به ۳۸۴ URL** رسیده است. تمام ۳۷۴ آدرس نسخه قبلی با fixture مستقل حفظ می‌شوند؛ هیچ URL قدیمی برای این توسعه حذف نشده است.

## شش مقاله جدید

```text
/blog/flatbed-handover-checklist
/blog/parking-garage-car-recovery
/blog/north-road-breakdown-location
/blog/tow-price-and-service-disputes
/blog/tow-truck-or-on-site-repair
/blog/roadside-help-without-internet
```

هشت مقاله بازنویسی‌شده: راهنمای اصلی امداد آنلاین، پیگیری پذیرش، هزینه حمل، پنچری، چراغ چک، تعمیرات مکانیک سیار، کارواش و حمل خودرو اتوماتیک. ساختار داده بخش‌ها اکنون از فهرست و جدول پشتیبانی می‌کند؛ قالب و رنگ‌بندی مقالات حفظ شده است. پیوندهای دعوت به درخواست، به فرم مستقل هدایت می‌شوند، نه کارت ثابت صفحه اصلی.

## حفظ ظاهر و امکانات قبلی

- فایل‌های صفحه اصلی، CSS سراسری، هدر، فوتر، هیرو، تصویرسازی یدک‌کش، کارت ثابت درخواست و پنجره خوش‌آمدگویی تغییر نکرده‌اند.
- شش تصویر قبل/بعد از هدر، هیرو و نوار خدمات، در دسکتاپ و موبایل **از نظر بایت PNG یکسان** بودند.
- برای صفحات جدید از اجزای ظاهری فعلی استفاده شده است. افزودن متن و جدول طبیعتاً طول صفحه مقاله/خدمت را بیشتر می‌کند، نه اینکه قالب سایت را عوض کند.
- مسیر پذیرش واقعی، قرارداد webhook، شماره‌ها، بله، شهرها، برندها و تنظیمات امنیتی production دست‌نخورده‌اند.

## داده و سنجش

رویداد `tool_used` فقط `tool_id` و مسیر صفحه را همراه نام رویداد می‌فرستد؛ پاسخ پرسش‌ها، مبلغ، کد دیاگ، نام، شماره همراه یا نشانی ارسال نمی‌شوند. شناسه‌های مجاز: `transport-selector`، `breakdown-guide`، `obd-code`، `quote-comparison` و `cost-calculator`.

این رویداد فقط استفاده از ابزار است، نه مشتری قطعی یا اعزام. `click_tel` نیز قصد تماس را نشان می‌دهد، نه مکالمه برقرارشده. تبدیل تجاری باید با داده عملیاتی کسب‌وکار سنجیده شود. هیچ داده خصوصی Search Console داخل برنامه یا این سند ذخیره نشده است.

## مرزها

- ابزارها مجوز ادامه رانندگی، تشخیص قطعی، نرخ رسمی، اعزام یا پرداخت ایجاد نمی‌کنند.
- ابزار مسیریابی جاده‌ای/GPS تازه ساخته نشده است؛ مسافت هزینه همچنان ورودی توافقی کاربر است.
- بهبود فنی و محتوایی، تضمین رتبه، ایندکس یا استناد موتورهای AI نیست.
- ثبت sitemap و «Discovered pages» با ایندکس‌شدن همه URLها یکسان نیست.
- تغییرات Cloudflare/WAF، پذیرش واقعی webhook و اندازه‌گیری CrUX مستقل از این کد هستند.

## استقرار پس از انتشار در GitHub

همه کار روی شاخه `arena/01a072dc-khodrochare` است. اگر سرور روی همین شاخه قرار دارد:

```bash
cd /var/www/khodrochare &&
git pull --ff-only origin arena/01a072dc-khodrochare &&
npm ci --include=dev &&
npm run build
```

سپس فقط پس از موفقیت build، سرویس فعلی سایت را با مدیر فرایند موجود restart کنید. فایل `.env` و فایل تأیید گوگل را حفظ کنید؛ از پاک‌سازی اجباری استفاده نکنید. Node 22 توصیه می‌شود. انتشار GitHub به معنی استقرار روی سرور اصلی نیست.

بعد از استقرار، حداقل `/pricing`، سه ابزار، یک مقاله تازه و دو صفحه اصلی امداد را با Test live URL بررسی کنید. sitemap همان `https://khodrochare.ir/sitemap.xml` است و فهرست کامل در `docs/google-indexing-urls.txt` قرار دارد. درخواست دستی را روی URLهای مهم متمرکز کنید؛ API، فروشگاه noindex و آدرس غلط را درخواست ندهید.
