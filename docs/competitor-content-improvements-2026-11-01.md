### تصمیم درباره نرخ‌نامه ارسالی

## تغییرهای کیفی مشخص

- **آنلاین:** بخش `#request` قبل از راهنمای طولانی قرار گرفت؛ CTA به دامنه واقعی مشتریان است. چهار بخش تازه، انتخاب خدمت، نشانی عملی، توافق و اطلاعات خصوصی را توضیح می‌دهند. مقاله پیگیری دارای نمونه پیام و جدول سه سناریو شد. قابلیت پس از ورود اپ، رهگیری زنده یا ویرایش خودکار آزمایش/تضمین نشده است.
- **هزینه:** تفاوت کفی و چرخ‌گیر و بازیابی اولیه از حمل روشن شد؛ سه حساب آموزشی و روش بررسی نرخ‌نامه به صفحه اضافه شد. مقاله مثال مستقل برای مقایسه دو پیشنهاد با مبلغ نهایی یکسان دارد. ماشین‌حساب و مبنای نرخ آن تغییر نکرد.
- **آزادراه:** راهنمای اختصاصی فقط برای `tehran-north` نمایش داده می‌شود؛ متن همه محورهای دیگر بی‌دلیل تکرار/به‌روز نشد.
- **شمال:** سه بند کلی/بی‌پشتوانه شامل «پرشمارترین سناریو»، قضاوت تعداد پایگاه‌های گلستان و توصیه ساعت ثابت سفر حذف شدند. به‌جای آن جدول دسترسی و تصمیم تعمیر یا حمل قرار گرفت. نسبت زمانی عددی و توصیه انتخاب مقصد فقط بر اساس نزدیکی نیز اصلاح شدند.
- **باتری:** جدول نتیجه موردنیاز تست و تفکیک هزینه/ضمانت به هاب اضافه شد. عنوان مقاله از القای قطعیت خرابی به «علائم خرابی باتری خودرو؛ چه وقت تست یا تعویض لازم است؟» تغییر کرد؛ جدول نشانه/احتمال/اقدام، پرسش پس از تست، چک‌لیست خرید و لینک درخواست اضافه شد.
- جدول‌ها از renderer مشترک با caption، سرستون `scope=col`، سرردیف `scope=row` و اسکرول محلی استفاده می‌کنند؛ JavaScript سمت کاربر تازه‌ای اضافه نشده است.
- تاریخ نمایشی ۵ landing و lastModified همان صفحات به 2026-11-01 تغییر کرد. تاریخ اصلاح ۳ مقاله نیز به همان روز رسید؛ تاریخ انتشارشان حفظ شد. sitemap مقاله از تاریخ همان مقاله استفاده می‌کند.

- `npm run lint`: موفق.
- `npm run build`: موفق.
- `npm run test:unit`: **۱۱۷ موفق**؛ شامل شکل جدول‌ها، ثبات تعداد مقاله‌ها، تاریخ ۵ صفحه و ۳ مقاله و دست‌نخوردن تاریخ هراز.

- `npm run test:seo`: **۴۷۵ صفحه بررسی‌شده، صفر خطا**؛ ۹۵ asset، ۴۴ variant تصویر، ۱۸ مسیر نامعتبر و ۱۵ redirect قدیمی بررسی شدند.
