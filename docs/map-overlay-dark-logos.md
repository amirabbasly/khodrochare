# پنل اطلاعات روی نقشه و لوگوهای دارک

## اصلاحات

- پلاک سفید لوگوها با زمینه سرمه‌ای گرادیانی و حاشیه آبی کم‌رنگ جایگزین شد. لوگوهای تک‌رنگ/خاکستری در نوار خانه با CSS به حالت نقره‌ای خوانا می‌رسند؛ لوگوهای رنگی رنگ خود را نگه می‌دارند و کمی روشن‌ترند. فایل اصلی لوگوها و لینک برندها عوض نشده‌اند.
- اطلاعات شهر انتخاب‌شده، لینک صفحه شهر، چهار آمار میانگین و چهار لینک خدمت داخل خود `.coverage-map-board` منتقل شدند. کارت با سطح نیمه‌شفاف روی نیمه پایین نقشه می‌نشیند و با نشان‌های استان‌های شمال تداخل ندارد؛ بخش تمام‌عرض مجزای زیر نقشه حذف شد.
- شرح بلند چهار خدمت، متن کامل میانگین آمار و شرایط هماهنگی در details بومی «جزئیات آمار و شرایط هماهنگی» داخل همین کارت نقشه هستند. متن حذف نشده و در HTML سرور باقی است؛ فهرست کامل سئویی ۵۹ لینک و هاب شمال نیز مانند قبل در بخش بازشدنی اصلی محفوظ‌اند.
- برچسب «میانگین در هر شهر» روی هر عدد آشکار است؛ نشانی شعب یا ظرفیت لحظه‌ای ساخته نشده است.
- شهرهای فهرست و نشان‌های نقشه با IntersectionObserver و CSS به‌ترتیب از پایین ظاهر می‌شوند. هنگام اسکرول فهرست، گزینه‌های تازه واردشده نیز ظاهر می‌شوند. انتخاب شهر خودکار عوض نمی‌شود و چرخش/اسکرول اجباری نداریم. حرکت حلقه نامحدود، درخواست شبکه یا رندر React در هر فریم ندارد.
- بدون JS/IntersectionObserver، CSS متن شهرها را مخفی نمی‌کند. حالت reduced-motion و فوکوس صفحه‌کلید جلوه را حذف و محتوا را آشکار نگه می‌دارند. این نکته فقط درباره انیمیشن جدید است؛ ادعای رفع محدودیت عمومی streaming سایت بدون JS نیست.
